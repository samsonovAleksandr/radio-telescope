### Повторить

Из корня репозитория с Python 3.11+ и NumPy выполните `python -m unittest discover -s tests -v`, `python hardware/check_cam.py` и `python antenna/verify.py`. Для интеграции используйте отдельный тестовый проект Compose. В .env задайте HTTP_PORT=18080. Сначала SIMULATE_SDR=0, выполните `docker compose -p hydrogen-qa up -d --build`, затем `python tests/container_checks.py`. Для [браузерного прогона](browser-checks.md) измените SIMULATE_SDR на 1 и повторите compose up. Для проверки сохранности зафиксируйте контрольные суммы файлов тома, выполните `docker compose -p hydrogen-qa up -d --force-recreate` и сравните суммы.
