# Браузерная проверка · 19 ноября 2026

Клиент Chrome 157.0.8103.79 в headless-режиме под Windows. Playwright Python 1.65.2. Проверен работающий контейнер по адресу http://127.0.0.1:18080 с SIMULATE_SDR=1. Измерительный прибор к USB для этого испытания не подключался.

| Действие в браузере | Критерий | Получено |
|---|---|---|
| Получить две demo-записи в профиле водорода и выбрать ON/OFF | 2048 каналов CSV, центр и края маскированы, избыток в полосе 1420,40575 ± 0,020 МГц выше соседнего фона | Средний избыток 61,1 %, контрольный интервал 1420,52…1420,70 МГц 0,0 % |
| График и выгрузки | Курсор меняет подпись, колесо и сброс обрабатываются, PNG имеет сигнатуру, разумные размеры и >5 кБ, JSON содержит синтетическое происхождение и идентификатор ON | Пройдено |
| Принятый шум и озвучивание спектра | В каждом режиме два проигрывателя, часы воспроизведения первого идут, ссылка экспортирует PCM WAV моно 32000 Гц/16 бит, более 1000 отсчётов | Пройдено для обоих режимов; акустический выход колонок не оценивался |
| Импорт interleaved CU8, тон +300 кГц | Импортированная запись помечена экспериментальной; максимум частоты в скачанном CSV 1420,300 МГц ± один канал | Пройдено |
| USB с имитатором | Показано состояние «Имитатор SDR», законченная запись доступна и остаётся демонстрационной | Пройдено |
| Остановка новой 15-секундной записи | Видны активная операция и управление остановкой; после остановки и обновления страницы частичная запись отсутствует, предыдущая доступна | Пройдено |

Отдельный прогон загрузил JSON демонстрации вместе с тестовым IQ. Поля настройки заполнились, модельное происхождение сохранилось при импорте.

В ходе теста исключений JavaScript не зарегистрировано. Прогон завершился с кодом 0. Проверка физического устройства, прослушивание человеком и испытания ВЧ-тракта выполняются отдельно.

## Воспроизведение

Тест создаёт записи с префиксом QA в **тестовом** хранилище. Нужен запущенный с SIMULATE_SDR=1 экземпляр со свободным имитатором. Установить библиотеку Playwright для Python, предоставить исполняемый файл Chrome/Chromium.

~~~sh
python tests/browser_smoke.py http://127.0.0.1:18080 --browser /usr/bin/chromium
~~~
